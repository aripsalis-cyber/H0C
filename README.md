# H0C — House of Chivalry

To edit the page, open `index.html` for the text and `styles.css` for its appearance. Open `index.html` in any web browser to preview it.

The page contains no server-side features and is suitable for free static hosting such as GitHub Pages, Cloudflare Pages, or Netlify. Before publishing, replace the marked recruitment/contact placeholder in `index.html` with the alliance's real contact information.
